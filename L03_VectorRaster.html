Case Study: This 4 km x 4 km section of Banks Peninsula terrain is shown as vector contour lines (every 50 m) and as a raster DEM grid (250,000 cells at 8 m resolution). The same real-world elevation is captured in fundamentally different ways.

Guided Questions

Q1

Toggle between Vector and Raster DEM views. Which representation makes it easier to identify a specific elevation (e.g., the 200 m contour)? Which better shows the continuous terrain surface?

Q2

The DEM has 8 m resolution (250,000 cells). The contour lines have far fewer vertices. What information is lost between contour lines that the raster preserves? What does the vector preserve that the raster does not?

Q3

Click a contour line and note the vertex count. Each vertex stores an [x, y] coordinate pair. How does the data storage per elevation value compare between the vector model (vertices along lines) and the raster model (one value per cell)?

Q4

If you needed to calculate the slope gradient at every point across this area, which data model would you use — vector contours or the raster DEM? Why?

Q5

An engineer needs to design a road route across this terrain, keeping the gradient below 10%. Would you deliver the data as contour lines, a DEM raster, or both? What resolution would be appropriate?
