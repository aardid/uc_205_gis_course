1Learning Objectives

  • Import and use core Python geospatial libraries (geopandas, matplotlib, pandas)
  • Read spatial data from multiple formats (GeoPackage, Shapefile, GeoJSON, CSV)
  • Inspect GeoDataFrame properties: geometry, attributes, CRS, and extent
  • Understand coordinate reference systems and reproject data using .to_crs()
  • Create basic choropleth maps using matplotlib
  • Export spatial data to GeoPackage format

3Step-by-Step Instructions

Section 1: Environment Setup

Import geopandas, pandas, and matplotlib. Verify all libraries load without errors. If you see an ImportError, ask your tutor for help installing the missing package.

Section 2: Understanding Geometry Types

Create Point, LineString, and Polygon objects using Shapely. Understand which geometry type represents which real-world feature. Visualise all three types side by side.

Section 3: Reading Spatial Data from Files

Load the Natural Earth world countries dataset using gpd.read_file(). This dataset ships with geopandas so no download is needed. Plot the world map to verify the data loaded correctly.

Section 4: Inspecting GeoDataFrame Properties

Use .head(), .info(), .crs, .total_bounds, and .geom_type to explore the dataset. Filter to New Zealand and inspect its properties. Complete the YOUR TURN exercise.

Section 5: Creating GeoDataFrames from CSV

Create a sample borehole dataset as a pandas DataFrame with Easting/Northing columns. Convert to a GeoDataFrame using gpd.points_from_xy(). Set the CRS to EPSG:2193 (NZTM2000).

Section 6: CRS and Reprojection

Check the CRS of your borehole data. Reproject from NZTM2000 to WGS84 using .to_crs(). Compare coordinates before and after reprojection. Calculate distances in both CRS to understand why a projected CRS is essential for engineering measurements.

Section 7: Choropleth Mapping

Create choropleth maps using .plot(column=..., cmap=...). Experiment with different colour maps and classification schemes. Complete the water table depth mapping exercise.

Section 8: Writing Data to GeoPackage

Save your borehole GeoDataFrame to a GeoPackage file using .to_file(). Add a second layer (WGS84 version) to the same file. Verify by reading the data back.
